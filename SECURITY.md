# Security policy

NormGate is under development. Phase 1 does not authorize or execute operations.
Do not use it as a production security boundary.

Maintainers must enable private vulnerability reporting and configure a monitored
security contact before accepting production reports. Until then, share findings
privately with the repository owner; do not open a public issue containing secrets
or actionable details about a deployed system.

Reports should identify the affected revision, a minimal synthetic reproduction,
expected boundary, and impact. No response-time guarantee exists yet. Supported
release windows and disclosure timelines will be established in Phase 6.

See `docs/security/threat-model.md` for implemented controls and outstanding work.
